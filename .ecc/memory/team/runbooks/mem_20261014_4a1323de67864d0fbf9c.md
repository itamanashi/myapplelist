# Outillage dev/QA myapplelist

- `tools/dev-chrome.ps1` : Chrome avec `--user-data-dir=.chrome-profile/` +
  `--load-extension=<root>`. 1er run = login + Agree, runs suivants = session conservée.
- `tools/qa-mal.mjs` : Playwright `launchPersistentContext(.chrome-profile, channel:'chrome')`,
  vérifie topbar/menus/avatar. Reste ouvert (les cookies s'écrivent à la fermeture).
- Playwright + `channel:chrome` bride les extensions : la topbar ne s'injecte PAS
  dans ce mode. Pour vérifier le rendu, inspecer le DOM live OU utiliser dev-chrome.ps1.
- `.chrome-profile/` et `.ecc/memory/project/` : gitignorés (cookies/session).
  `.ecc/memory/team/` : versionné (contexte partageable).
- Après modif content/ : `node --check`, reload extension (chrome://extensions), refresh MAL.
