# Refonte profil par relocalisation (2026-10-14, `buildProfileView` dans content.js)

- Vraie refonte = on DÉPLACE les nœuds MAL dans notre layout, pas de re-scrape :
  avatar `.user-image`, `ul.user-status`, liens actions (regex href animelist/mangalist/statistics/history/favorites),
  `.user-profile-about`, `.stats.anime/.manga`, sections h5 génériques.
- Pseudo depuis l'URL (`/profile/<user>`) : le h1 contient aussi les liens header, inutilisable.
- Sections h5 nichées (updates + favoris "Anime (10)"...) : chaque h5 + siblings suivants
  jusqu'au prochain h5, où qu'ils soient. Updates ("...Updates") -> colonne latérale
  avec libellés FR, favoris -> colonne principale.
- `.content-container` d'origine masqué (vide après déplacement) + bandeau h1 masqué
  sur `body.myapple-profile`. Échec (try/catch) = page native intacte.
- Uniquement sur `/profile/<user>` exact (pas /statistics, /favorites...).
