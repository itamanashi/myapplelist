# Avatar MAL en lazyload (leçon apprise 2026-10-14)

- Sur la page profil, l'avatar est `<img class="lazyload" data-src="https://cdn.myanimelist.net/s/common/userimages/<uuid>_225w?...">`
  SANS attribut `src`. En HTML fetché+parsé, `.src` vaut `""`.
- `og:image` de la page profil = icône MAL par défaut (`/sp/icon/apple-touch-icon-256.png`),
  INUTILISABLE comme photo.
- Ordre correct : `getAttribute("data-src")` d'abord, puis `.src`, puis `og:image` en dernier recours.
- Cache `chrome.storage.local` 24h par pseudo + garde anti `/sp/icon/` (révoque l'ancien logo).
- Code : `enhanceAvatar()` dans `content/content.js` (fetch same-origin + DOMParser).
