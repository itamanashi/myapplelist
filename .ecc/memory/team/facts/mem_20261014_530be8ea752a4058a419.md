# Slots pub MAL et trous vides (vérifié 2026-10-14, panel.php)

- Colonne droite panel.php : 1er widget = slot pub 300x250 (`article.widget-container.right`
  > `div.widget` > `div.ad-sas`). Avec adblock, la créa est bloquée mais le conteneur
  garde 250px de vide entre le titre et "My Statistics".
- Fix : `article.widget-container:has(.ad-sas) { display: none !important; }`
  (collapse le conteneur entier, pas juste la créa).
- Classe obfusquée changeante (`kVwNpRmQxHtBjYcL-nvwtus`) : ne pas cibler, `.ad-sas` est stable.
- Titre page (`h1.h1` "My Panel") : div nu sous `#contentWrapper`, plein-bleed via
  `width:100vw + margin-left:calc(50% - 50vw)`, taille 20px (pas le clamp géant des h1).
