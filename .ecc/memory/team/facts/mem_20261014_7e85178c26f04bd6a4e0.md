# Header MAL connecté (vérifié 2026-10-14, compte itaminashi)

- `#headerSmall` > `#header-menu` : Hide Ads, liste (Anime/Manga List), messages, notifs, profil.
- Connecté : toggle `a.header-profile-link` (pseudo seul, SANS href) + dropdown
  `.header-profile-dropdown` dont l'entrée "Profile" = `/profile/<pseudo>` exact
  (regex : `/\/profile\/[^/]+\/?$/`).
- Piège : `a[href*="/profile/"]` matche d'abord `/profile/<user>/stacks`
  (Interest Stacks), PAS le profil. Ne jamais l'utiliser seul.
- AUCUNE image avatar dans le header connecté. La photo est sur la page profil.
- Invité : `a[href*="login.php"]` dans le même scope.
- Règle : scope header uniquement, jamais `document` (auteurs des news).
